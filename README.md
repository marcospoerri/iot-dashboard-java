# IoT Dashboard Java

Dieses Projekt simuliert IoT-Sensordaten (Temperatur, Luftfeuchtigkeit) und zeigt sie in einem Java-Backend mit Spring Boot an. Die Daten werden in einer Cloud-Datenbank gespeichert.

## Features
- REST-API für Sensordaten
- Cloud-Datenbank-Anbindung
- Docker-Containerisierung
- Deployment auf Azure oder AWS

## Setup
1. Clone das Repository.
2. Starte das Spring Boot Projekt.
3. Verwende Postman oder ein Skript, um Sensordaten zu senden.
